## 更新这份记录

部署或改造完容器后更新 `.local.md`，并遵守：

- 顶部标注更新时间，说明数据以 `docker image ls` / `docker container ls -a` / `docker system df` 为准
- **不写入密钥、令牌、密码、`.env` 的具体内容**；只写路径与变量名
- 本机绝对路径可以写（`.local.md` 不进版本库）
