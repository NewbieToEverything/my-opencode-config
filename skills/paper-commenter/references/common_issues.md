# 常见学术写作问题与识别指南

22 类常见统计、实验、图表问题的识别方法和建议措辞。

---

## 统计方法问题

### P值误用

**常见表现：**
- 大量 p 值刚好低于 0.05
- 对同一数据反复做统计检验直至显著
- 将 p > 0.05 直接解释为"无差异"
- 未报告效应量或置信区间
- 使用 p 值而不考虑实际意义

**审阅时如何识别：**
- 看是否所有显著结果 p 值都在 0.05 以下但接近 0.05
- 检查是否做了过多子组分析
- 看是否每个检验都区分了 confirmatory vs exploratory
- 检查 effect size 和 confidence interval 是否报告

**建议措辞：**
"作者报告了多个统计检验但未提及多重比较校正。建议明确区分验证性分析和探索性分析，对探索性结果应视为生成假设而非检验假设。"

### 多重比较未校正

**常见表现：**
- 同时进行大量假设检验不做校正
- 子组分析过多
- 事后比较未说明校正方法

**审阅时如何识别：**
- 统计检验次数是否远超过预期
- 是否在 Methods 中声明了校正方法
- 是否在 Results 中区分了主要分析和次要分析

**建议措辞：**
"本文进行了 XX 次独立的统计检验。建议使用 Bonferroni 校正或 FDR 控制来处理多重比较问题，或说明为何不做校正。"

### 样本量不足

**常见表现：**
- 未做 priori power analysis
- 小样本下使用大样本假设的方法
- 结论强度远超样本量能支撑的范围
- 未讨论统计功效限制

**审阅时如何识别：**
- 检查是否有 power analysis 或 sample size justification
- 评估 effect size vs sample size 是否合理
- 看局限性讨论是否提及样本量问题

**建议措辞：**
"研究样本量为 N=XX，但未提供统计功效分析。建议补充 power analysis 或讨论当前样本量对统计检验力的限制。"

### 伪重复

**常见表现：**
- 将重复测量当作独立样本
- 将同一批数据的多个度量当作统计单位
- 忽略数据的层级结构

**审阅时如何识别：**
- 检查统计单位是否与实验单位一致
- 看是否使用了适当的层级模型
- 检查样本量报告是否混入了重复测量

**建议措辞：**
"文中报告的 N=XX 可能包含伪重复。请确认统计单位是否与实验单位一致，必要时使用混合效应模型或正确聚集数据。"

### 循环分析 / 数据窥探

**常见表现：**
- 先看数据再据此提出假设
- 在同数据上进行探索和验证
- 根据 p 值决定分析策略
- 直到得到显著结果才停止收集数据

**审阅时如何识别：**
- 假设是否在收集数据前预注册
- 分析方法是否在 Methods 中预先声明
- 是否有单独的训练集和测试集

**建议措辞：**
"本文的分析方法似乎是在查看数据后决定的。建议明确声明哪些分析是预先计划的（hypothesis-driven），哪些是事后发现的（data-driven）。"

### 缺失数据处理不当

**常见表现：**
- 简单删除所有缺失值不做说明
- 未做缺失机制分析
- 插补方法不合理
- 无敏感性分析

**审阅时如何识别：**
- 检查缺失数据的比例和模式
- 看是否说明了缺失机制（MCAR/MAR/MNAR）
- 是否进行了敏感性分析

**建议措辞：**
"作者删除了 XX% 的缺失数据未做进一步分析。建议报告缺失模式，说明缺失机制假设，并考虑多重插补或敏感性分析。"

## 实验设计问题

### 混杂变量未控制

**常见表现：**
- 两组除自变量外存在系统性差异
- 未测量或未报告已知混杂因素
- 未做协变量分析

**审阅时如何识别：**
- 看两组基线特征是否可比
- 检查是否测量了已知混杂因素
- 看是否使用了匹配或协变量校正

**建议措辞：**
"实验组和控制组在 XX 方面存在显著差异（p<0.05），该变量可能是混杂因素。建议调整此变量或讨论其对结论的潜在影响。"

### 控制组 / 对照组不足

**常见表现：**
- 缺乏基线对照组
- 对照组不匹配（两组差异系统化）
- 仅使用历史对照
- 无安慰剂/空白对照

**审阅时如何识别：**
- 对照组条件是否除自变量外完全一致
- 历史对照是否在相同条件下收集
- 是否有 Hawthorne 效应未被控制

**建议措辞：**
"本文使用历史数据作为对照。历史对照可能存在多种未控混杂因素，建议补充同期对照实验。"

### 随机化缺失

**常见表现：**
- 未使用随机分配
- 分配方法不透明
- 未做分配隐藏
- 准实验设计未讨论随机化缺失的影响

**审阅时如何识别：**
- 检查 Methods 是否描述了随机化方法
- 分配是否对实验者隐藏
- 非随机设计下是否做了倾向性评分匹配

**建议措辞：**
"本文未提及随机化方法。若因实际情况无法随机化，建议说明原因并讨论潜在的混杂方向。"

### 批次效应

**常见表现：**
- 不同时间、不同批次收集的数据被混合分析
- 批次与实验条件混淆
- 未做批次校正

**审阅时如何识别：**
- 检查数据收集是否分多个批次
- 验证批次是否与实验条件系统相关
- 看是否使用了 ComBat 等批次校正方法

**建议措辞：**
"数据来自多个批次，且批次与实验条件存在混淆。建议使用 ComBat 等批次校正方法，或至少讨论批次效应对结果的影响。"

### 样本选择偏误

**常见表现：**
- 排除标准不合理或未说明
- 纳入/排除导致样本与目标人群不一致
- 只报告了有利的子集
- 便利抽样代替随机抽样

**审阅时如何识别：**
- 纳入/排除标准是否在 Methods 中明确
- 样本与目标人群的可比性
- 排除比例是否过大（>20%）
- 是否报告了排除流程图

**建议措辞：**
"本研究排除了 XX% 的潜在参与者但未充分说明排除原因。建议补充纳入/排除流程（PRISMA 流程图），并讨论排除偏倚的可能方向。"

## 可复现性问题

### 方法描述不足

**常见表现：**
- 缺少关键实验参数
- 超参数和实现细节缺失
- 随机种子未固定
- 预处理步骤描述不清

**审阅时如何识别：**
- 是否有足够细节让独立研究者复现
- 是否提及了软件版本和硬件配置
- 关键参数是否已报告

**建议措辞：**
"实验设置缺少 XX 参数，其他研究者无法复现。建议补充完整的参数配置、软件版本和随机种子。"

### 数据不可用

**常见表现：**
- 数据未公开
- 仅提供样本数据而非完整数据
- 数据格式不标准
- 数据使用限制未说明

**审阅时如何识别：**
- 数据可用性声明是否明确
- 数据集是否在适当仓库中存储
- 访问方式是否清晰

**建议措辞：**
"文中未提供数据可用性声明。建议在开放科学框架（如 Figshare、Zenodo）上发布匿名化数据。"

### 代码不可用

**常见表现：**
- 代码未公开
- 代码不完整或有硬编码路径
- 缺少环境配置说明
- 使用专有软件且未说明

**审阅时如何识别：**
- 代码可用性声明是否存在
- 代码仓库中是否有 README 和依赖说明
- 关键分析是否可重现

**建议措辞：**
"核心分析代码未公开。建议将代码上传至 GitHub 并附上环境配置（如 requirements.txt 或 environment.yml）。"

### 验证缺失

**常见表现：**
- 训练和测试来自同一分布
- 无交叉验证或独立验证集
- 仅在单一数据集上评估
- 没有做稳定性分析

**审阅时如何识别：**
- 评估方法是否在 Methods 中详细说明
- 是否有独立测试集（非同一批次）
- 对随机性是否有控制（多次运行报告均值和方差）

**建议措辞：**
"模型评估仅在单次划分的训练/测试集上进行。建议使用交叉验证或多次随机划分以报告性能的置信区间。"

## 解释偏差

### 过度解读结果

**常见表现：**
- 将相关解释为因果
- 从小样本得出泛化结论
- 夸大效应大小
- 忽略了结果的不确定性范围

**审阅时如何识别：**
- 检查结论是否与方法论能力相匹配
- 看是否有 qualifying language（suggest, may, could）
- 摘要和结论中的措辞是否比 Results 更强

**建议措辞：**
"结论部分声称'XX 导致 YY'，但本研究的设计是相关的（correlational）。建议将因果表述改为关联性表述，如'XX 与 YY 相关'。"

### 因果推断不当

**常见表现：**
- 观察性研究做了因果论断
- 未考虑反向因果关系
- 未讨论遗漏变量偏误
- 未使用因果推断方法（如 IV、DiD、RDD）

**审阅时如何识别：**
- 研究设计是否支持因果推断
- 是否讨论了潜在的混淆方向
- 是否对因果识别的假设进行了检验

**建议措辞：**
"本文基于观察性数据得出因果结论。观察性研究无法排除遗漏变量偏误。建议修改表述或考虑使用工具变量等方法。"

### 选择性报告

**常见表现：**
- 报告的结果与 Methods 中声明的不一致
- 只报告显著结果，不报告不显著结果
- 事后改变主要结局指标
- 未报告所有假设检验结果

**审阅时如何识别：**
- 比较 Methods 中的分析计划与 Results 中的报告
- 看是否有 outcome switching（主要结局改变）
- 检查是否所有声明检验都报告了结果
- 是否有预注册（可验证一致性）

**建议措辞：**
"Methods 中声明分析了 5 项指标，但 Results 仅报告了其中 3 项。请补充其余分析的结果，即使是阴性结果也应当报告。"

### 忽略替代解释

**常见表现：**
- 结论排除了其他合理解释
- 未讨论 competing hypotheses
- 未考虑实验者期待效应
- 未提及已知的反向证据或矛盾发现

**审阅时如何识别：**
- 是否诚实地讨论了局限性
- 是否评估了替代假设的合理性
- 是否引用了不一致的文献

**建议措辞：**
"作者将结果归因于 XX，但另有 YY 和 ZZ 等合理的替代解释未被讨论。建议补充对这些替代解释的评估。"

## 图表诚信

### 图像篡改 / 不当处理

**常见表现：**
- Western blot 条带重复或拼接
- 图像中出现了不连续的背景痕迹
- 对比度/亮度调整掩盖了差异
- 不同组图像来自同一来源

**审阅时如何识别：**
- 检查图像背景是否均匀
- 看拼接处是否有可见边界或克隆痕迹
- 对照度/亮度调整是否在合理范围内
- 检查重复条带或区域

**建议措辞：**
"图 3 中的 Western blot 图像背景不连续，可能存在裁剪或拼接。请提供原始未经处理的全膜图像以供验证。"

### 误差线定义不清

**常见表现：**
- 误差线含义不明确（SD/SEM/CI）
- 小样本使用 SEM 代替 SD（更窄）
- 误差线缺少标注
- 用 SEM 进行组间比较时产生视觉误导

**审阅时如何识别：**
- 图注是否标注了误差线类型
- SEM vs SD — SEM 是 SD 的 1/√n，看起来更窄
- 重复数据的展示方式是否适当（是否用 dot plot）

**建议措辞：**
"图 2 的误差线未标注类型。SD 描述数据离散程度，SEM 描述均值的精度。建议统一标注并考虑使用 SD 或添加原始数据点。"

### 颜色 / 可视化误导

**常见表现：**
- 热力图颜色选择不适合色盲读者
- y 轴不从零开始夸大了组间差异
- 使用 3D 图导致视觉失真
- 刻度选择偏向某一方向

**审阅时如何识别：**
- 是否考虑了色盲友好（红绿色盲最常见）
- y 轴截断是否标注了断点
- 3D 可视化是否必要
- 坐标轴范围是否合理

**建议措辞：**
"图 5 使用红绿配色，红绿色盲读者无法区分。建议改用蓝橙配色或添加形状和纹理标记。"
