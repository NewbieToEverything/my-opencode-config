# Agents Orchestrator

## 先选后端，再查本机说明

只加载当前请求涉及的后端。优先使用已安装版本的帮助、接口规范和随包文档；不要在 skill 中复制参数目录。文档入口失效时，重新定位安装目录，不安装软件、不切换后端。

- OpenCode：[references/opencode.md](references/opencode.md)。HTTP 接口以本机 OpenAPI 为准；安全封装见 [references/api-v2.md](references/api-v2.md)。
- Hermes：[references/hermes.md](references/hermes.md)。普通任务优先 CLI，需要运行中输入或精确取消时再查 ACP。持续目标另读 [references/hermes-goals.md](references/hermes-goals.md)。
- pi agent：[references/pi.md](references/pi.md)。优先随包 CLI、会话和 RPC 文档。

## 只读查询

查找或读取会话不等于授权执行任务。先按关键词、项目、来源缩小候选范围，再读相关会话。检查分页、时间和父子会话关系；不要批量导出无关历史。

只查到一个存储位置不能证明其他位置没有会话。查不到时，检查该工具支持的项目、profile、会话目录或运行实例选择。直接检查存储只用于受支持接口不足的情况；不得读取凭据或隐藏配置。

## 已授权的执行

- 明确目标、项目目录、约束和验收条件，保护已有改动。读取历史本身不授权启动 worker。
- 给执行代理提供必要上下文，并明确禁止读取隐藏配置、泄露敏感信息、越界修改及未授权安装或删除。
- 记录后端、准确会话 ID、目录、模型/推理档位和自建进程 ID。返工续接原会话，不用 latest，不静默创建替代会话。
- 区分输入已接收、正在执行、等待权限、模型失败和实际完成。超时先核对状态，不盲目重发；客户端退出不等于后台任务取消。
- 不擅自更换模型、后端或范围，不重启共享服务。遵守后端已有的明确授权例外。
- 独立检查改动和验收结果。报告关键结果、未完成项和遗留进程；不得用 worker 自述代替验证。

## 信息边界

现有凭据只能由程序内部使用。提供商、配置、会话和工具响应都可能含敏感字段；在进入模型或日志前做字段白名单过滤。不要原样输出凭据端点、配置或无关历史。只报告任务所需的非敏感字段。

本机帮助或源码证明接口存在，不证明推理、权限拦截和恢复行为已验证。明确区分文档能力与运行证据。
